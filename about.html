About The Local PDF

Three PDF utilities that run inside your browser, built because the alternative was uploading payslips to a website nobody had heard of.

AboutUpdated 2 August 2026

Why this site exists

Merging a few documents is a two-minute job that the web has made oddly complicated. Search for a PDF tool and you find services that ask you to create an account, wait in a queue, accept a watermark, or — most commonly — upload the document to a server so it can be processed somewhere else and downloaded back.

For a great many documents that last step is the problem. Payslips, ID scans, medical letters, and client contracts are exactly the files people need to merge and compress, and exactly the files that should not be handed to an unfamiliar processor because a browser tab asked nicely.

Modern browsers can do this work themselves. The Local PDF is what that looks like: three tools, no account, no upload, no queue, no watermark, and no file ever leaving the machine it started on.

How it works

Everything happens in JavaScript in your tab. When you add a file, the browser reads it into memory on your device. Processing runs there, the result is assembled in memory, and your browser hands it to you as a download. There is no server component — this site is static files and nothing else.

Two open-source libraries do the heavy lifting:

  • pdf-lib parses, rebuilds, and writes PDF documents. It handles merging and the lossless compression pass.
  • Mozilla's PDF.js renders pages to a canvas — the same engine Firefox uses to display PDFs. It powers the shrink tool's page re-rendering.

You can verify all of this without trusting us. Load any tool page, disconnect from the internet, and keep working. A tool that uploads your file cannot function offline.

What we deliberately do not do

  • No accounts. There is nothing to sign up for and no user data to lose.
  • No file storage. Not briefly, not encrypted, not at all — there is no server to store anything on.
  • No Office conversion. Rendering Word or Excel faithfully needs an engine browsers do not have. Any site offering it is processing your file remotely, and we would rather tell you to export to PDF yourself.
  • No watermarks, page caps, or paid tier. The site is funded by advertising, which is why you see ads on these pages.

How the site is funded

The tools are free and there is no premium version. Running costs are covered by advertising served through Google AdSense. Ads are placed around the written content and between sections — never over the tools themselves, and never in a way that interferes with using them.

Advertising is served by a third party, and unlike the tools it does involve cookies and, in some regions, a consent choice. That is described in full in our privacy policy. What advertising never involves is your documents: they are not transmitted anywhere, so no advertiser, analytics provider, or anyone else can see them.

Editorial approach

The guides are written by the same people who build the tools, from problems we actually hit: a scan that would not fit under a portal limit, a merged file that came out upside down, a compression pass that saved nothing. Where we give numbers — file sizes, resolutions, attachment limits — they come from testing or from providers' own documentation, and we say when a figure is a rough range rather than a rule. We do not run affiliate links or sponsored posts, and when a tool on this site is the wrong answer to a problem, the guides say so.

If something here is wrong or out of date, tell us and we will fix it.
